# Job Portal

A React-based Job Portal application that allows users to browse jobs, search for opportunities, save jobs for later, and view detailed job information.

## Features

* Browse available job listings
* Search jobs by title
* View detailed job information
* Save jobs to local storage
* Remove saved jobs
* Dynamic routing with React Router
* Loading and error handling states
* Responsive design for mobile and desktop
* Deployed on Vercel

## Technologies Used

* React
* React Router DOM
* JavaScript (ES6+)
* CSS3
* Fetch API
* Local Storage
* Vite
* Vercel

## Installation

1. Clone the repository

```bash
git clone <https://github.com/sumitjadhav99/job-portal>
```

2. Navigate to the project directory

```bash
cd job-portal
```

3. Install dependencies

```bash
npm install
```

4. Run the development server

```bash
npm run dev
```

5. Open the application in your browser

```text
http://localhost:5173
```

## Build for Production

```bash
npm run build
```
